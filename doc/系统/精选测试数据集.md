# 需脉枢纽 · 精选测试数据集（curated）

> 版本：v1.0 ｜ 更新：2026-08-13 ｜ 定位：**贴近真实场景的测试与优化基线**（10 家高质量厂商 + 10 条行业知识）
> 数据文件：`backend/scripts/data/curated_vendors.json` + `curated_knowledge.json` ｜ 种子脚本：`backend/scripts/seed_curated.py`

## 1. 目标

现有 100 家模板厂商（随机模板）只能测"能否命中"，测不出**匹配区分度、verdict 三态、解析溯源、答疑/推荐质量**。精选数据集用"**虚构公司名 + 真实行业参数**"构造贴近真实的场景基线，驱动全链路：匹配（通道A向量 + 通道B参数）→ 解析（parse_capability 文档→参数）→ 解释（explain 溯源）→ 答疑（domain_qa）→ 推荐（recommend_slots）。

## 2. 设计原则

1. **参数维度对齐匹配契约**：匹配读取 `product_types / os_support / certifications / application_scenarios / interfaces / moq / lead_time_days`（+summary_text 兜底），每家覆盖；
2. **每家一份真实能力文档**：真实写入存储（溯源 preview 可用，修复 seed 虚拟文档 404），文本内嵌参数，可被 parse_capability 解析验证；
3. **覆盖匹配三态**：matched / partial / missing（缺项）/ 高配慢单（测 moq/lead 排序）；
4. **多品类覆盖**：机顶盒 4 / 智能音箱 3 / IoT 3；
5. **虚构名 + 真实参数**：规避真实厂商法律风险，保留行业真实感；
6. **golden 标注**：每家的"正确解析结果"手工标注，供评估断言（slot_extraction_f1 / e2e_top1）。

## 5. 用法与验证

```bash
# 运行（cwd=backend，幂等）
python scripts/seed_curated.py
# 或容器内
docker compose exec api python scripts/seed_curated.py
```

**验证清单**：
1. 精选厂商 10 家入库（`source_type="curated"`）+ 双轨向量；
2. 能力文档预览可用（documents/preview 按 file_id 返回真实内容，非 404）；
3. 构造典型买家需求 → 匹配：V1/V5/V8 类应进 Top，V2/V3/V6/V7/V9 呈现 partial/missing 解释，V4 呈现 moq/lead 扣分梯度；
4. 答疑命中 curated 知识（含来源）；
5. `parse_capability` 对 curated 文档重解析可复现 tags（验证解析链）。

**回归入口**：精选场景可转评估集条目（golden 标注），作为 L3 评估 CI 的黄金集基础。
