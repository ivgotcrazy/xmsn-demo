## 页面与组件清单（厂商端） 
### 1. 全局页面地图（Page Map） 
采用树状结构，标注页面ID、名称、模块归属和跳转关系。所有页面统一采用桌面端宽度 **1440px**，高度按内容自适应（Figma中可用Frame高度自定义）。

```plain
00-公共模块
├── 00A-注册页（选择角色）
│   ├── 选“我是厂商” → 01A
│   └── 选“我是采购方” → 02A（自动登录）
├── 00B-登录页
│   ├── 厂商登录 → 01B
│   └── 采购方登录 → 02A
└── 00C-首页（可选，Demo可跳过）

01-厂商端
├── 01A-厂商注册详情页
│   └── 注册成功 → 01B
├── 01B-厂商控制台
│   └── 入口 → 01C
├── 01C-能力材料导入页（仅文档）
│   └── 文档解析完成 → 我的档案(01D)
└── 01D-能力档案页（只读）
    └── 返回 → 01B（可随时回看）

02-买家端
└── 02A-需求对话Agent页（会话一体化：会话列表 / 对话 / 当前需求+匹配记录）
    ├── 确认并提交匹配 → 生成匹配记录卡片，弹窗展示匹配结果（不跳页）
    └── 点击匹配记录卡片 → 弹窗回看该次匹配结果

03-管理员后台
├── 03A-管理员登录页（独立，或复用00B但选择管理员角色）
│   └── 登录成功 → 03B
├── 03B-数据概览页（Dashboard）
│   ├── 快捷入口 → 03C / 03D
│   └── 卡片点击可跳转对应列表页
├── 03C-需求与匹配查看页
│   └── 点击行 → 抽屉/详情页（需求详情）
└── 03D-厂商产品查看页
    └── 点击行 → 详情页（厂商能力档案）
```

**设计提示**：在Figma中，可将每个页面建为一个顶层Frame（1440×自适应），页面间的跳转关系用Prototype中的连线表示，方便演示时点击流转。

**设计提示**：管理员后台采用经典的“侧边导航+顶部面包屑”布局，与厂商控制台风格一致但配色可区分（如深蓝色主题）。所有列表页支持分页、搜索、筛选。在Figma中，可使用同一套后台组件库。

#### 01D · 能力档案页（只读） 
| 属性 | 说明 |
| --- | --- |
| **对应PRD** | 1.5 能力档案生成（AI自动·只读） |
| **布局结构** | 纵向单列：顶部**档案元信息行**（版本 vN · 更新于 MM-DD HH:mm · 基于 N 份文档）+ 状态徽标（审核中/已通过）+ 一句话能力摘要条；**综合评估区（纯文字，无图表）**：能力完备度 X/N + 缺失项标红带建议 + 低置信度字段提示（黄文字）；**能力档案区**（按能力 Schema 遍历渲染：硬能力分组 + 软标签分组，每行 = 状态图标 + 字段名 + 值 + **置信度列** + source_map 溯源"文档·第N页"可预览）；底部"原始文档"列表。 |
| **核心组件** | `COMP-015`摘要卡片、`COMP-009`能力档案列表（schema 驱动，含置信度列）、`COMP-010`综合评估（文字）、`COMP-011`缺失项提示、`COMP-016`加载骨架屏 |
| **关键交互** | ① 加载显示`COMP-016`骨架屏，3-5秒后替换为真实数据；② 综合评估为**纯文字**（无进度条）："能力完备度：已提取 X 项硬能力（共 7 项），M 项缺失"；有低置信度字段时黄字提示"以下字段解析把握不足（置信度 <60%）：…"；③ 缺失硬能力字段整行标红"未提取" + 红色建议（如"月产能：建议补充「产线产能介绍」文档"）；④ 软标签缺失显示中性"未填写"（不标红）；⑤ 每个已提取能力值**独立置信度列**显示百分比（来自 `source_map[field].confidence`，<60% 黄色），并展示溯源"文档·第N页"（`source_map`），点击打开大尺寸预览（94vw×92vh）定位高亮；⑥ 页面内容与能力 Schema（CAPABILITY_SCHEMA_FIELDS）一一对应。 |
| **数据绑定** | 档案字段来自大模型解析的 JSON，映射为 `structured_tags`（key 与能力 Schema 一致）；**版本/时间/文档数来自 `version` / `updated_at` / `doc_count`（每次增删文档重新解析后递增/更新）**；摘要来自 `summary_text`；完备度文字来自 `completeness`（或由结构化数据计算）；**字段级置信度来自 `source_map[field].confidence`（无总体 parse_confidence）**；溯源来自 `source_map`；状态来自审核状态（审核中/已通过）。 |
| **异常状态** | ① 解析失败：骨架屏替换为错误提示"AI解析暂时不可用，请稍后重试"，可返回 01C 重新上传；② 低置信度：该字段置信度列黄色 + 综合评估区黄字提示补文档。 |
| **Figma建议** | 能力档案列表用 Auto Layout 纵向排列，行内 flex：状态图标(18px 圆) + 字段名(固定宽) + 值(自适应) + 置信度列(固定宽,右对齐) + 溯源(右对齐链接)；缺失行用 Error 底色；综合评估区用文字 + 标签（无进度条/图表），颜色 Token 区分（Success/Warning/Error）。 |

**Figma设计系统最终建议**：

+ 将所有组件（共39个）整理到一个独立的`Design System`页面，按“基础组件”、“业务组件”、“后台组件”分组。
+ 每个组件制作成Component Variants，并设置Auto Layout、Constraints，确保可复用。

+ 原型交互：使用Prototype面板连接页面，设置Smart Animate，模拟页面跳转、抽屉滑出、模态框弹出、选项卡切换等效果。
